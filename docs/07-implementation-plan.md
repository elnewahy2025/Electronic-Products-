## نقاط تنفيذية متبقية (قبل الإطلاق)
1. المراجعة القانونية لنص الإقرار وسياسة الخصوصية وسطر «لا استرداد»
2. وثيقة حدود الخطط الفعلية (Vercel, Google API, Supabase, خدمات المعالجة، خدمة التنزيل، التخزين الإداري)
3. اختيار خدمات المعالجة والتنزيل الفعلية + التحقق من التكلفة
4. اختيار مزود التخزين السحابي الإداري + مفاتيح التشفير
5. تحديد حد السعر الأدنى للمنتجات من لوحة Super Admin
6. تحديد سياسة الخصوصية وTerms of Service
7. تحديد خطة الإطلاق التدريجي (نسبة البائعين، عدد المنتجات، إلخ)

## الخطوة التالية في التنفيذ
- مصفوفة RLS التفصيلية لكل جدول (SELECT/INSERT/UPDATE/DELETE لكل دور)
- ثم ملفات migration فعلية
