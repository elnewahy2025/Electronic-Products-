# وثيقة متطلبات منصة بيع المنتجات الرقمية — النسخة النهائية
تاريخ الإغلاق: 21 نوفمبر 2026
الحالة: نطاق مغلق، كل القرارات محسومة

## 1. الملخص التنفيذي
منصة عربية متعددة البائعين لبيع المنتجات الرقمية. الزائر يتصفح دون حساب. البائع ينشر منتجاته من حساب معتمد. الملفات الأصلية في Google Drive البائع. المنصة تدير الطلبات والأكواد والتنزيل. الدفع خارج المنصة في المرحلة الأولى، مع بنية تسمح بإضافته لاحقًا.

## 2. الأدوار
- الزائر: تصفح + بحث + معاينات
- المشتري: حساب اختياري، إدارة طلباته وأكواده
- البائع: إدارة منتجاته وملفاته وحسابات Drive
- الموظف: صلاحيات مخصصة
- الأدمن: صلاحيات إدارية
- Super Admin: كل الصلاحيات

## 3. المصادقة
| الدور | طريقة الدخول | 2FA |
|---|---|---|
| البائع | Google Login | اختياري |
| المشتري | Google + بريد/كلمة مرور | اختياري |
| الموظف | Google + بريد/كلمة مرور | إلزامي (حجب كامل حتى التفعيل) |
| الأدمن | Google + بريد/كلمة مرور | إلزامي |
| Super Admin | Google + بريد/كلمة مرور | إلزامي |

- اعتماد البائع إلزامي قبل الدخول، ويُعاد التحقق عند كل دخول
- إقرار البائع إلزامي عند أول دخول، ورفضه يمنع الدخول

## 4. المنتجات والملفات
- البائع يضيف/يعدل/يحذف منتجاته دون موافقة مسبقة
- الإدارة تشرف وتوقف وتعليق
- السعر يحدده البائع، والحد الأدنى للإدارة
- أنواع الملفات من لوحة التحكم
- لا حد أقصى عام لحجم الملف، ملتزم بحدود Google Drive
- رفع مباشر من المتصفح إلى Drive (لا يمر عبر Vercel)
- البائع يربط عدة حسابات Drive، مع توزيع تلقائي واختيار يدوي
- المعاينات تلقائية، البائع يعدلها
- فحص تلقائي للملفات (امتداد + MIME + توقيع)
- عزل الملفات المشبوهة

## 5. العلامة المائية (قرار نهائي)
- على المعاينات فقط
- النص: `{platform_name} — نسخة غير مرخصة`
- قطرية، كثافة متوسطة
- بدون رقم طلب أو معرف مشتري
- الفيديو: ثابت + دوري
- الأصل المسلّم بدون علامة

## 6. الأكواد والتنزيل
### كود الشراء
- فريد تمامًا، لا كود مشابه لكود سابق مطلقًا
- بصمة آمنة (`code_hash`) لا نص صريح
- صلاحية 72 ساعة من الإصدار
- تفعيل مرة واحدة فقط

### رحلة التنزيل
- 3 محاولات كحد نهائي لكل منتج (order_item)
- ZIP كامل = محاولة واحدة
- الملفات المنفردة = محاولة واحدة عند اكتمال كل ملفات الإصدار
- جلسة 4 ساعات (قابلة للتعديل من Super Admin)
- فشل ZIP قبل الاكتمال: لا يستهلك محاولة، ويُعاد داخل الجلسة
- فشل ملف فردي قبل الاكتمال: لا يستهلك، يُعاد داخل الجلسة
- انقطاع Drive أثناء جلسة نشطة: إلغاء بلا احتساب محاولة + تعويض إداري

### الجلسة الجزئية
- إذا انتهت 4 ساعات بعد تسليم جزئي: لا تُحتسب محاولة
- تُغلق الجلسة، تُفتح جلسة جديدة للمتبقي فقط (بطلب من الإدارة)
- الملفات المسلّمة لا تُعاد

### التعويض
- 3 جلسات كحد أقصى **لكل منتج منفرد** (code_id)
- يبدأ بطلب من الإدارة فقط، بسبب إلزامي
- لا يستهلك محاولة
- يسلّم الملفات المتبقية فقط

### طلب استثناء المحاولات
- يُنشأ بعد استنفاد الـ3
- Super Admin فقط يقرر
- `granted_attempts` متغيّر، بلا حد أعلى، مع تحذير عند تجاوز `warning_threshold`

### منع الإلغاء بعد التسليم
- بمجرد تأكيد تسليم الكود: **لا إلغاء ولا سحب من أي شخص، بما فيهم Super Admin**
- بعد بدء جلسة التنزيل: **لا إلغاء للجلسة نهائيًا**
- محاولة الإلغاء تُرفض وتُسجَّل كحدث `*_blocked_after_delivery`
- `code.revoked` فقط قبل التسليم (`issued → delivered`)

### تأكيد التسليم
- إرسال تلقائي + تأكيد يدوي
- مَن يؤكد يدويًا: Super Admin + الأدمن + موظف بصلاحية `code.confirm_delivery`

### كود بديل
- الكود المنتهي دون تفعيل بسبب خطأ إرسال: كود بديل مجاني مرتبط بالكود الأصلي
- لا يُحتسب طلب شراء جديد

### إعادة إرسال نفس الكود
- مسموح بلا حد قبل التفعيل
- ممنوع بعد التفعيل

### نزاع "لم يصلني"
- الإدارة تراجع سجل الإرسال (`code_delivery_attempts`) وتقرر
- القرار مسجّل في `audit_logs`

### حالة Revoked للجلسات
- فقط للجلسات التي فشلت تقنيًا **قبل بدء التسليم**
- النظام يقترح + الإدارة تؤكد

## 7. التقييمات
- نجوم + نص
- وحدة التقييم: منتج منفرد داخل عملية الشراء
- تقييم واحد لكل منتج لكل مشتري، يُمنع مطلقًا بعد ذلك
- قيد فريد `(product_id, buyer_id)`
- يظهر «مشتري موثّق» فقط
- المشتري لا يعدّل ولا يحذف
- البائع والأدمن يحذفان بسبب إلزامي
- Super Admin يعدّل ويحذف

## 8. المالية
- العملة الافتراضية: USD
- Super Admin يحدد العملات المتاحة وأسعار الصرف
- البائع يختار من القائمة المعتمدة
- سعر الصرف يُثبَّت **لحظة الشراء فقط**
- العملات: EGP, KWD, SAR, USD
- حد الصرف الافتراضي: 100 USD (قابل للتعديل)
- العمولات مرنة لكل بائع ونوع

## 9. النسخ الاحتياطي
- تلقائي أسبوعي (قابل للتعديل)
- يدوي لـ Super Admin فقط
- النطاق: قاعدة البيانات + الملفات
- التخزين: سحابي خاص بالإدارة، مستقل عن Drive
- تشفير عند الراحة بمفاتيح منفصلة
- الاحتفاظ: 90 يومًا افتراضيًا
- الاستعادة: Super Admin فقط
- اختبار استعادة دوري إلزامي

## 10. سجل التدقيق
- Append-only: لا UPDATE ولا DELETE من أي دور، بما فيهم Super Admin
- الاحتفاظ: 180 يومًا، ثم أرشفة إلى تخزين بارد
- القراءة: الأدمن + الموظف بصلاحية `audit.read`
- الكتابة عبر مسار خادمي فقط

## 11. سياسة الإلغاء والاسترداد
- **لا استرداد مالي** (الدفع خارج المنصة)
- `purchase_request.cancelled` ممكنة قبل تأكيد تسليم الكود فقط
- بعد تأكيد التسليم: لا إلغاء مطلقًا

## 12. قرارات مفتوحة سابقة — مُغلقة
| الموضوع | القرار |
|---|---|
| جلسة جزئية انتهت | لا محاولة، جلسة جديدة للمتبقي |
| تعريف الاكتمال | البائع يحدد ملفات الإصدار |
| العلامة المائية | معاينات فقط، النص المعتمد |

## 13. نقاط تنفيذية متبقية
1. المراجعة القانونية لنص الإقرار وسياسة الخصوصية وسطر «لا استرداد»
2. وثيقة حدود الخطط الفعلية (Vercel, Google API, Supabase, خدمات المعالجة)
3. اختيار خدمات المعالجة والتنزيل الفعلية
4. اختيار مزود التخزين السحابي الإداري
5. تحديد حد السعر الأدنى من لوحة Super Admin
