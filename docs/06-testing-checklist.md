# قائمة الاختبارات الإلزامية قبل الإطلاق

## الأمان والصلاحيات
- [ ] منع بائع من الوصول إلى ملفات أو بيانات بائع آخر
- [ ] اختبار صلاحيات الزائر والمشتري والبائع والموظف والمدير
- [ ] حجب الوصول الكامل حتى تفعيل 2FA لكل دور إداري
- [ ] رفض الدخول لموظف لم يُفعّل 2FA
- [ ] رفض طلب استثناء من غير Super Admin
- [ ] منع تعديل أو حذف أي صف في audit_logs حتى بحساب Super Admin
- [ ] التحقق من أن الأصل المسلّم غير موسوم، وأن المعاينة موسومة
- [ ] منع البائع من تعديل العمولات وأسعار الصرف والأكواد

## الأكواد والتنزيل
- [ ] رفض كود انتهت صلاحيته بعد 72 ساعة
- [ ] منع تفعيل الكود أكثر من مرة
- [ ] انتهاء جلسة التنزيل بعد 4 ساعات
- [ ] عدم تجاوز 3 محاولات عند الطلبات المتزامنة
- [ ] اختبار تنزيل ZIP واختبار تنزيل الملفات منفردة
- [ ] عدم احتساب فشل تقني على أنه تسليم ناجح
- [ ] اختبار الجلسة الجزئية: لا محاولة، جلسة جديدة للمتبقي فقط
- [ ] رفض الجلسة التعويضية الرابعة لنفس المنتج
- [ ] قبول granted_attempts المتغيّر وتطبيقه بدقة
- [ ] منع تسليم ملف مكتمل مرتين داخل نفس الجلسة
- [ ] إعادة تنزيل ملف انقطع قبل اكتمال تسليمه مسموحة دون احتساب
- [ ] فشل ZIP قبل الاكتمال: لا محاولة، يُعاد داخل الجلسة

## منع الإلغاء بعد التسليم
- [ ] رفض إلغاء الكود بعد تأكيد التسليم لكل الأدوار
- [ ] رفض إلغاء الجلسة بعد بدء التسليم لكل الأدوار
- [ ] تسجيل محاولة الإلغاء المرفوضة في audit_logs
- [ ] إصدار كود بديل مجاني مرتبط بالكود المنتهي دون احتساب طلب جديد
- [ ] رفض إصدار أي كود مطابق أو مشابه لكود سابق
- [ ] إعادة إرسال نفس الكود قبل التفعيل بلا حد

## النسخ الاحتياطي والاستعادة
- [ ] استعادة نسخة احتياطية كاملة تشمل البيانات والملفات
- [ ] تشغيل نسخة احتياطية يدوية من Super Admin مع تسجيلها
- [ ] أرشفة سجل تدقيق بعد 180 يومًا مع بقاء البحث والاستعادة

## ربط Drive
- [ ] اختبار إلغاء تفويض Drive وامتلاك الحساب وتحويل التخزين
- [ ] اختبار انقطاع Drive أثناء جلسة نشطة: إلغاء بلا محاولة + تعويض

## الملفات والرفع
- [ ] رفع ملف كبير واستكمال الرفع بعد انقطاع الاتصال
- [ ] إثبات أن الملف لا يمر عبر Vercel في مسار الرفع المعتمد
- [ ] عزل الملفات المشوهة ومنع نشرها
- [ ] منع حذف إصدار سبق بيعه نهائيًا

## التقييمات والعملات
- [ ] منع تقييم ثانٍ لنفس المنتج من نفس المشتري (بقيد قاعدة البيانات)
- [ ] التحقق من تثبيت سعر الصرف لحظة الشراء لا لحظة العرض
- [ ] التحقق من تطبيق حد الصرف الافتراضي (100 USD) وتعديله

## سجل التدقيق
- [ ] اختبار سجلات التدقيق وعدم قدرة البائع على العبث بها
- [ ] اقتراح النظام إبطال جلسة فاشلة تقنيًا قبل التسليم، وتأكيد الإدارة فقط
- [ ] ظهور علامة الفيديو ثابتة ودورية معًا في المعاينة
